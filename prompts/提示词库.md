# 提示词模板库（面试展示用）

> 演示样例。把占位符换成你自己的业务信息和人设即可复用。

## 1. 选题调研

```
角色：你是巴西跨境电商领域的 B2B 内容策划。
输入：以下政策动态与竞品账号近期内容 {{材料}}。
任务：输出 5 个适合小红书/公众号/视频号的选题，每个选题包含：目标卖家痛点、标题候选 2 个、内容钩子、预期咨询引导方式。
要求：用卖家视角，不用政策文件口吻；避免夸大和承诺收益。
```

## 2. 三平台脚本一次生成

```
基于选题 {{选题}}，按同一事实生成三种版本：
- 公众号：800-1200 字深度图文，结构含开头钩子、3 个要点、行动清单、咨询引导；
- 小红书：3 篇笔记，每篇含封面短标题（≤12 字）、正文分点、结尾钩子；
- 视频号：45 秒口播脚本，按 0-3 秒 / 3-20 秒 / 20-35 秒 / 35-45 秒分段，写成大白话。
统一人设：{{你的人设}}。所有专业信息标注来源，不确定的不编造。
```

## 3. AI 数字人 / 口播

```
把以下脚本改写成适合数字人口播的版本 {{脚本}}：
- 拆成短句，每句不超过 20 字；
- 标注停顿和重音位置；
- 开头 3 秒必须有钩子；
- 结尾明确引导评论区关键词。
```

## 4. 评论与私信线索初筛

```
你是线索初筛助手。输入一条评论或私信：{{内容}}。
按以下规则输出 JSON：
- 标签：入驻咨询 / 税务合规 / 物流清关 / 价格敏感 / 泛咨询
- 判断依据：命中了哪些关键词
- 建议回复：一句话，提供对应资料或引导转接业务同事
- 优先级：高 / 中 / 低
规则：{{规则清单}}
```

## 5. 数据复盘

```
输入本周三平台数据 {{数据}}。输出：
1. 曝光→互动→私信→有效线索的漏斗转化率；
2. 表现最好的 2 个选题及原因假设；
3. 下周选题和提示词的具体调整建议（每条都要可验证）。
不写空泛总结，只写能执行的动作。
```
