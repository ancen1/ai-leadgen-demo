## 不打印纸质版怎么做

作品集完全可以电子化，面试当天这样做：

1. 按上面的步骤发布到 GitHub Pages，得到一个链接。
2. 用草料二维码等工具把链接生成二维码；可以贴在纸质简历角落（简历打印 2 份就够），也可以不贴，面试时直接说"我带了电子版作品集，可以扫码看"。
3. 提前在手机里打开一次链接并加到主屏幕，避免现场网络慢；面试官看纸质简历时，你把手机递过去展示 Demo 即可。
4. 作品集截图都在第 06 板块，点开可放大，面试时讲到哪张就翻到哪张。

## 发布到 GitHub Pages（面试前必做）

1. 新建公开仓库，例如 `ai-leadgen-demo`。
2. 在本目录执行：

```bash
git init
git add .
git commit -m "AI content lead-gen workflow demo"
git branch -M main
git remote add origin https://github.com/<你的用户名>/ai-leadgen-demo.git
git push -u origin main
```

3. 仓库页面 → Settings → Pages → Build and deployment：Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)` → Save。
4. 等待 1-2 分钟，访问 `https://<你的用户名>.github.io/ai-leadgen-demo/` 确认手机能打开。
5. 生成二维码（微信/草料二维码均可），贴在纸质简历右上角和作品集首页。

## 工作流 SOP（面试时按这个讲）

1. **选题调研**：政策动态 + 竞品账号 + 评论问题 → 选题清单与痛点排序
2. **AI 生产**：选题 + 人设 → 三平台脚本、标题与封面文案（提示词模板化）
3. **数字人/口播**：脚本 → AI 口播或数字人成片 + 剪映包装
4. **矩阵发布与线索初筛**：三平台分发 + 评论区关键词规则 + 私信话术
5. **数据复盘**：跟踪曝光→互动→私信→有效线索，反哺下一轮选题与提示词

## 90 秒讲解词（照着练）

> 我做这个 Demo 是为了验证一件事：内容能不能用 AI 从「发稿」变成「获客」。我拿巴西税改这个真实选题，先做政策与竞品调研，再用模板化提示词一次生成公众号、小红书、视频号三种表达，视频号用 AI 口播完成，最后用关键词规则对评论和私信做线索初筛，并把数据写回复盘表。整个过程中我把重复环节固化成 SOP，下一步的优化点是把初筛规则接到自动化工具上。演示里的文案和数据是样例，实际投递前我会换成自己跑通的产出。
