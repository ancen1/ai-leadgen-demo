# 案例包：一个选题，三平台落地

> 演示样例。请替换成你自己用 AI 实际跑出来的版本。

## 0. 选题卡

- 选题：巴西税改落地——5 税合并为 2 税，跨境卖家现在要做什么
- 目标人群：准备进入或已经经营巴西站的中小跨境卖家
- 核心痛点：政策看不懂、合规成本不确定、担心清关被卡
- 内容钩子：「不是税变多了，是申报逻辑变了；这三类卖家最受影响」
- 线索引导：评论区回复「巴西」领取《开店与合规资料清单》

## 1. 公众号图文（结构样例）

标题：巴西税改落地：5 税并 2 税，跨境卖家最该关注的 3 个变化

开头Hook：过去一周，问得最多的不是「巴西市场好不好」，而是「我现在的账务要不要重做」。答案没那么复杂，但确实有人会因此踩坑。

正文结构：
1. 变化一：流转税简化，申报口径变了，不是税率简单加减
2. 变化二：发票与合规要求更刚性，低报货值风险上升
3. 变化三：小额进口税收规则调整，直邮小包成本模型要重算
4. 对三类卖家的影响：新手入局 / 已有本土店 / 做海外仓备货
5. 行动清单：资料准备、账务梳理、清关核验三步

结尾：政策原文与清单整理好了，评论区回复「巴西」，或后台私信「合规」领取。

## 2. 小红书笔记（3 篇角度）

笔记 A｜封面标题：巴西开店前先看这张图｜正文：5 个资料清单 + 2 个高频被拒原因 + 结尾引导私信「清单」。

笔记 B｜封面标题：税改后小包还能做吗｜正文：用一张对比图讲小额进口税变化，给出成本测算思路，结尾提问「你走直邮还是海外仓？」

笔记 C｜封面标题：巴西清关踩坑实录｜正文：HS 编码、低报货值、发票不一致三类问题，给出自查清单，结尾引导评论「自查」领表格。

注意：小红书标题前置痛点、封面文字不超过 12 字、正文分点短句、每条都留咨询钩子。

## 3. 视频号短视频（AI 口播）

时长：45 秒。形式：AI 数字人 / AI 口播 + 剪映字幕。

脚本结构：
- 0-3 秒：「巴西税改落地，最慌的其实是这三类卖家。」
- 3-20 秒：三个变化，每条一句人话解释
- 20-35 秒：给一个具体行动清单
- 35-45 秒：「完整清单评论区回复巴西，我发你。」

## 4. 线索初筛规则（字符串关键词版）

- 含「开店 / 入驻 / 资料 / 流程」→ 标签：入驻咨询 → 推送资料清单话术
- 含「税 / 合规 / 发票 / 申报」→ 标签：税务合规 → 转业务顾问
- 含「清关 / 物流 / 海外仓 / 时效」→ 标签：物流清关 → 转供应链同事
- 含「多少钱 / 报价 / 费用」→ 标签：价格敏感 → 先发案例再约谈
- 其他 → 标签：泛咨询 → 进入普通私信队列

## 5. 复盘记录（样例）

第一版：标题偏政策解读，互动率一般；第二版把标题改成卖家视角的「我要做什么」，私信数提升。结论：B 端内容要先说痛点再说政策，钩子要给具体资料而不是「欢迎咨询」。
